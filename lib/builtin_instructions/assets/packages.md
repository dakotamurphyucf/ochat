# Reusable capability packages

Reuse the ordinary checked ChatML projects and module interfaces actually supplied
by the host. Compose explicitly selected instructions, tools and helpers through
those declared dependencies. Keep source provenance and the selected interface
visible when explaining what a package provides.

Installed library sources are an immutable inventory. Export only to an explicit
caller-selected destination; preparing an exported project still needs legitimate
source grants for its complete dependency tree. A source example is not evidence
that a live host has provided every capability it describes.

Importing instructions or modules does not instantiate a tool or expand authority.
Use the existing project dependency mechanism rather than inventing another
registry or fetch path. Respect current host policy for every supplied tool and
report a missing capability instead of simulating its effects.
