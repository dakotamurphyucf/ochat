# ChatML inference graph copy

The [internal type-graph copier](../../lib/chatml/chatml_type_graph_copy.mli) gives the module-interface probe and future transactional REPL typing one traversal over mutable inferred types. It copies all supplied roots under one physical-cell identity map. A copied variable cell is installed before its `Bound` body is traversed, so a cycle closes inside the copy. Shared cells stay shared, while free-cell names, levels and equality obligations and immutable generic names retain their meaning. No mutable cell in a detached result refers to an input cell.

`copy_detached` is the candidate-typing entry point. Its caller supplies explicit nonnegative limits for roots, type-constructor visits, distinct variable cells, traversed child/variable edges, work steps and depth. A root begins at depth one; an empty graph has depth zero. Repeated structural visits and edges count again, while a previously seen variable does not cause its bound body to be re-traversed. Each root, type visit, edge, new cell and physical-identity comparison consumes work. The cell lookup still uses a physical association list, so worst-case work in the number of distinct cells is quadratic; the work limit bounds that cost. Depth is capped at 256 by policy to keep the current recursive traversal conservative. Counts and checkpoint calls occur while processing roots, list items, row fields and identity searches, with no unbounded prepass. On a limit failure or checkpoint exception, no partial result escapes and original cells remain untouched.

The existing [module-interface probe](../../lib/chatml/chatml_type_probe.mli) uses the same copier in its legacy compiler-owned path. It retains original cells and before-images for its established commit protocol: first validate rigid-parameter escape, prepare projected contents, check originals are unchanged, then perform the short non-cancellable write phase. Fresh cells introduced while probing are projected into fresh committed cells, so later probe mutation cannot change committed types. Its public API, caller-owned graph assumption and checkpoint behavior are unchanged.

The [generated graph tests](../../lib/chatml/chatml_type_graph_copy_tests.ml) enumerate small directed graphs with free leaves, cross-root sharing and cycles. A canonical cell-ID witness compares exact free name/level/equality metadata and structure before and after copying, while pairwise identity checks and mutations verify detached isolation. A compact wrapper graph covers every inferred type constructor. The tests exercise each limit, exact accepted boundaries, an empty graph under zero limits and propagation of the same checkpoint exception during identity search. The existing [probe tests](../../test/chatml_module_scope/type_probe_tests.ml) verify commit, stale-original rejection and rigid escape after extraction. This helper does not seed REPL inference counters, map value scopes or decide statement publication; OCH-269 owns those contracts.
