## Boundary qualification

Searches covered protocol/session/server/client/ChatML modules, and the closed operation/event/lifecycle types were read directly. The missing shared run record is a bounded source conclusion across these surfaces; it is not an assertion that no internal function anywhere uses the word “run”. Existing session/operation receipts are the required starting point.

The design sketch references existing `Agent_protocol.Session.t`, `Agent_protocol.Id.Session.t`, `Agent_protocol.Id.Operation.t` and `Agent_protocol.Error.t` (which re-exports `Protocol_error`), `Agent_protocol.Session.Message_content.t` and validated `Agent_protocol.Idempotency_key.t`. Its proposed Run/Host types and methods do not currently exist. Formatting and parsing validate the sketch only; production codecs, method names and implementation remain downstream work.

Current process checks are documented separately in [validation](validation.md). The final installed unified helper, side-effect-safe extracted command libraries and workflow run completion remain implementation acceptance gates.
